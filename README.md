# 🧩 HTML-Parser-C  
### Recursive Descent HTML Parser with DOM Tree Construction  

> A lightweight command-line HTML parser built in **C**, demonstrating core **compiler design concepts** — including lexical analysis, CFG-based parsing, DOM tree construction, and error handling.

---

## 🚀 Features

- **Lexical Analysis** – Tokenizes HTML into opening tags, closing tags, self-closing tags, attributes, and text nodes.  
- **Recursive Descent Parsing** – Enforces a defined **Context-Free Grammar (CFG)** for proper tag nesting and syntax validation.  
- **DOM Tree Construction** – Builds an in-memory tree structure representing the document hierarchy.  
- **Error Detection & Recovery** – Handles mismatched/missing tags, malformed attributes, and unexpected tokens with clear diagnostics.  
- **Self-Closing Tag Support** – Recognizes and validates tags like `<br/>`, `<img/>`, `<input/>`, etc.  
- **Command-Line Options** – Flexible modes for testing and validation.  

---

## 🧮 Command-Line Options

| Flag | Description |
|------|--------------|
| `--validate-only` | Parses and validates syntax without showing the DOM tree. |
| `--show-tree` | Prints the constructed DOM tree in a hierarchical format. |
| `--tokens` | Displays token stream generated by the lexer. |
| `--input <filename>` | Specifies the HTML file to parse. |
| `--help` | Displays usage information. |

**Example Usage:**
```bash
./html_parser --input sample.html --show-tree
./html_parser --validate-only --input index.html
./html_parser --tokens --input test.html
